# tourism-gap-finder

지역 관광 데이터 기반 관광 콘텐츠 빈틈 분석 및 추천 서비스입니다.

## 프로젝트 구조

```text
tourism-gap-finder/
├── frontend/          # 프론트엔드 애플리케이션
├── backend/
│   └── app/           # 백엔드 애플리케이션 소스
├── data/
│   ├── collectors/    # 데이터 수집 스크립트
│   ├── processors/    # 데이터 전처리·변환 스크립트
│   └── analysis/      # 분석 코드와 결과물
├── docs/              # 기획·기술 문서
├── README.md
└── .gitignore
```

빈 디렉터리는 Git에서 공유될 수 있도록 `.gitkeep` 파일을 포함합니다.
