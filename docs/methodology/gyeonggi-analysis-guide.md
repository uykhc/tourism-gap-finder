# 경기도 관광 콘텐츠 비교 기준

## 비교 대상

- 전체 비교군: 경기도 28개 시 (군은 표본 부족으로 현재 제외)
- 포트폴리오 지표: TourAPI 등록 콘텐츠의 유형별 구성비와 유형별 개수/km²
- 우수 관광지 기준: 최신 공통 월의 방문자 수 40% + 관광 자원 수요 30% + 관광 수요 강도 30% 종합점수 상위 5개 시
- 반경 지표: 기초지자체 중심 관광지 정보 API의 2025년 3월 순위 상위 3개 관광지를 중심으로 반경 1km·2km 내 음식점·숙박·문화시설·행사·쇼핑 개수

## 해석 주의사항

우수 관광 지역은 최신 공통 월의 방문자 수(40%), 관광 자원 수요(30%), 관광 수요 강도(30%)를 28개 시 안에서 각각 백분위화해 합산한 상위 5개 시입니다. 선정된 5개 시의 콘텐츠 구성비와 면적당 콘텐츠 수 분포는 참고값으로만 제공하며, 자동 임계값이나 부족 후보 판정은 하지 않습니다. threshold는 팀의 새 정의가 확정된 뒤 적용합니다.

방문자 수는 기간 내 일별 순방문자 수의 합계이며, 고유 개인 수나 순수 관광객 수가 아닙니다. 이동통신 데이터만으로 정확한 방문 목적을 구분할 수 없고, 기초지자체 방문자 수를 하위 행정구 수치로 임의 합산하면 안 됩니다.

기본 설정의 `visitor_type_names`는 비어 있어 API 응답의 모든 방문자 구분값을 사용합니다. 첫 실행 뒤 결과 JSON의 `observed_visitor_type_names`를 확인하고, 필요한 경우 설정에 포함할 구분값만 입력해야 합니다.
