## 7. 종합 인사이트

경주시는 문화관광과 숙박의 등록 공급 수준은 비교한 우수 지역보다 높게 나타나는 반면, 체험관광은 두 우수 지역 모두보다 상대적 공급이 낮고 등록 장소 1곳당 목적지 검색량도 가장 높습니다. 따라서 현재 지표만 놓고 보면 전 관광 유형을 일괄적으로 확충하기보다 체험관광에서 실제 미충족 수요가 존재하는지 우선 검증하는 접근이 타당합니다. 다만 카카오맵 등록 장소 수는 실제 프로그램 수나 시설 수용능력을 완전히 반영하지 않으므로, 체험관광 부족을 확정하기 전에 세부 유형·관광권역·운영시간·예약 가능량을 추가 확인해야 합니다. 우수 지역 사례에서도 대형 시설형과 반복 프로그램형이 모두 확인되므로 특정 투자 방식 자체를 모방하기보다 기존 자원에 새로운 경험을 결합하는 방식과 반복 운영을 통해 콘텐츠를 축적하는 방식을 구분해 참고할 필요가 있습니다.

- 근거 — 상대 공급: 우수 지역 2곳 모두보다 낮음, 최저 0.70배
- 근거 — 장소당 검색량: 6개 유형 중 1위 (2,117.6)
- 참고 사례 — [case-01](#case-01) 포항 스페이스워크, [case-03](#case-03) 서산 해미읍성 역사체험축제

**2. 시설 없이 반복 프로그램으로 공급 늘리기**

대규모 시설 투자에 앞서 기존 장소를 활용한 반복 프로그램으로 실제 참여수요를 검증하는 경로를 우선 검토할 수 있습니다. 특히 비수기·야간·가족 단위 등 구체적인 이용자와 시간대의 공백이 확인될 경우 소규모 실증사업으로 효과를 확인한 뒤 확대 여부를 판단하는 방식이 적합합니다.

- 근거 — 포항 스틸아트페스티벌은 2012년부터 지역 산업 정체성을 활용한 축제를 반복 운영
- 참고 사례 — [case-02](#case-02) 포항 스틸아트페스티벌, [case-04](#case-04) 포항국제불빛축제

### 유의할 점

- 등록 공급이 적고 장소당 검색량이 높다는 관찰일 뿐, 공급을 늘리면 방문객·체류시간·소비가 증가한다는 인과는 확인되지 않았습니다.
- 쇼핑은 우수 지역 두 곳의 상대 공급 방향이 엇갈려 독립적인 공급 부족 유형으로 판단하기 어렵습니다.
- 사례는 사업 방식의 참고 자료이며, 해당 사례의 관광성과가 경주에서도 동일하게 나타날 것이라는 근거는 아닙니다.

## 한계

- 공급은 카카오맵에 해당 유형으로 등록된 장소 수를 이용한 대리변수이며, 실제 프로그램 수·운영시간·예약 슬롯·수용인원·품질을 직접 측정하지 않습니다.
- 목적지 검색량은 관광객의 실제 방문 또는 미충족 수요와 동일하지 않으며, 반복 검색·지역주민 이용 등 검색행태가 포함될 수 있습니다.
- 유형별 지도 등록 방식과 검색행태가 서로 달라 `검색량 ÷ 장소 수`의 유형 간 단순 순위를 실제 공급 부족 규모로 해석해서는 안 됩니다.
- 시 전체 면적 기준 공급밀도는 관광객이 집중되는 실제 관광권역의 공간적 공급 수준을 충분히 반영하지 못합니다.
- 방문자는 이동통신 기반 일별 순방문자로, 2박 3일 체류가 3일로 집계됩니다.
- 화면 개발용 예시 응답이며 분석 수치 자체는 실제 분석 결과가 아닙니다. 실제 정책 판단에는 원자료 검증과 관광권역·세부 체험유형·운영능력에 대한 추가 분석이 필요합니다.
